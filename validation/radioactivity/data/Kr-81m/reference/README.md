# Kr-81m selected reference

Use ENSDF (Basunia, evaluated September 2024, NDS 199,271 (2025)) for
parent identity, 13.10(2) s half-life and IT/EC timing. Use the retained
MIRD Summary Spectrum for explicit line energies and absolute yields;
that CSV does not establish its own nuclear-evaluation identity.

Kr-81m itself is the requested metastable parent. Its selected 190.46 keV
MIRD IT photon and conversion/atomic products are present. The MIRD gamma
plus conversion yield reproduces the ENSDF 99.9975% IT branch to table
precision; ENSDF's 190.44 keV photon differs slightly and is not averaged.
The Br atomic lines have the tiny direct 0.0025% EC scale. Later EC decay of
ground-state Kr-81 (about 2.13e5 y) is excluded. Explicit MIRD Auger rows
are line laws, unlike unsupported LNHB grouped ranges. Weak X-ray lines are
split only to keep every positive yield reachable in the finite ticket space.

Neutrinos, recoil and additional radioactive daughter decays are excluded.
