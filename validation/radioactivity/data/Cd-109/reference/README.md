Selected authority: CEA/LNE-LNHB, M.-M. Be and E. Schonfeld, LNHB/PTB, 2014.

Exclude the 88.0341 keV Ag-109m isomer's delayed transition (39.7 s),
its 88.0336 keV photon and all associated conversion electrons. The compact
LNHB/LARA X-ray totals include this delayed conversion component.

`omega_K * [P_K + alpha_K/(1 + alpha_T)]`. Retain only its prompt EC term:
`0.831 * 0.812 = 0.674772` K photons per parent. Distribute it using the
evaluated K ratios `53.05 : 100 : 27.7 : 4.82` (sum 185.57), with the
four compact LARA energies. This supported normalization is independent
of the mixed absolute totals. Mixed L/Auger laws are excluded.
ENSDF agrees on 461.9 d but gives a 39.79 s isomer half-life; MIRD's
atomic inventory has a different scope and is not used to fill omissions.
