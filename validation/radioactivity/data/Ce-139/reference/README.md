# Ce-139 selected reference

Selected authority: CEA/LNE-LNHB, LNHB/INEEL, 2008.

Select prompt La nuclear and atomic relaxation after EC, including
the 165.8575 keV photon and its shell conversion law. The directly
populated 165.8576 keV level has a 1.499 ns half-life; it is prompt
relaxation under the current marginal-source convention. This introduces
no lifetime cutoff. The auxiliary Ce isomer is not the requested parent.

270 keV. MIRD's gamma yield 0.789378 differs from selected 0.799.
Neither cross-check replaces selected absolute emission values.
