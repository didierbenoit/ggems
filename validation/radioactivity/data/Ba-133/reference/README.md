# Ba-133 selected reference

Selected authority: CEA/LNE-LNHB, V. P. Chechev and N. K. Kuzmenko, KRI, 2015; 2016 tables.

Select the ground-state EC parent, prompt nuclear photons, compact
absolute Cs X rays and PenNuc shell conversion lines. Capture probabilities
and auxiliary Ba-133 isomer datasets do not create primary groups.
The selected daughter levels have picosecond/nanosecond lifetimes and
describe prompt relaxation under the marginal-source convention.

The evaluation commentary recommends 3849.3(23) d, with 10.539(6) y as
its alternate representation. Convert that directly evaluated day value
with 86400 s/d; no assumed year length or rounded seconds field is used.
ENSDF's ground-state 10.551 y differs. LARA photon energies and PenNuc
compact shell energies retain their distinct published rounding; neither
ENSDF nor MIRD replaces these selected laws.

Complete evidence remains in [raw/](../raw/). Unsupported Auger energy
laws, neutrinos, recoil and additional radioactive daughter decays are
excluded. See the [generic validation instructions](../../../README.md).
